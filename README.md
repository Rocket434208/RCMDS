## About

RCMDS is a free Windows PowerShell customizer created by Repsi. Transform your boring terminal into a personalized experience with custom wallpapers, animated effects, seasonal decorations, modern typography, and more.

No complicated setup. Just one command.

## Installation

Open Windows PowerShell and paste the following command:

```powershell
irm https://raw.githubusercontent.com/Rocket434208/RCMDS/main/Install-RCMDS.ps1 | iex
```

Once installed, type `rcmds unlock` to enable all customization features.

## Features

- Custom wallpapers and gradient backgrounds
- Adjustable background blur and tint
- Animated snowfall and snowflakes
- Falling autumn leaves
- Floating sparkles
- Rounded seasonal window decorations
- Custom fonts and text sizes
- Personalized welcome messages
- Animated startup loading screen
- Compact command prompt
- Administrator support
- Automatically saved preferences

## Commands

| Command | Description |
|---|---|
| `rcmds help` | View all available commands |
| `rcmds unlock` | Unlock all features |
| `rcmds version` | View the current version |
| `rcmds wallpaper` | Use your desktop wallpaper |
| `rcmds blur 25` | Adjust background blur |
| `rcmds overlay snow` | Enable snowfall |
| `rcmds overlay leaves` | Enable falling leaves |
| `rcmds decoration snow` | Enable snow decorations |
| `rcmds effects off` | Disable all effects |
| `rcmds admin` | Open as administrator |
| `rcmds diagnose` | Troubleshoot effects |

## Requirements

- Windows 10 or Windows 11
- Windows PowerShell 5.1
- Windows Terminal
- Internet connection for installation
